# Usurper Reborn v1.1.6

A small release to get one fix onto the server.

## Fixed

- **The world boss line is on Main Street only.** The countdown before the
  boss and the live status during it were drawn on every screen in town, the
  shops and the dungeon entrance included, which was spam. Now it is one line
  in one place. `/boss` still shows the countdown or the status from anywhere,
  and the mail, news, Discord post, and hour-before call are unchanged, so a
  player who wakes at the Inn, at home, or at the castle and never passes
  Main Street still hears about the boss.

## Tests

1,150 passing, unchanged.
